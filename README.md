# Portal Plan Curricular 2024-I — V1.6

Versión casi definitiva del portal de socialización del **Plan Curricular 2024-I Actualizado** de la Escuela Profesional de Ingeniería Electrónica.

## Alcance de esta versión

- Diseño institucional y responsive para escritorio, tablet y móvil.
- Navegación: Inicio, El Plan, Malla, Documentos y Participa.
- Malla curricular actualizada proporcionada para el proyecto.
- Documentos del Plan Curricular, sumillas y tabla de equivalencias proporcionados para el proyecto.
- Acceso a la encuesta de socialización existente.
- Acceso al nuevo formulario de comentarios y sugerencias.
- Sin contadores propios de visitas, encuestas o comentarios.
- Sin Google Apps Script, backend ni credenciales de Google dentro del portal.
- El portal puede publicarse como sitio estático en GitHub Pages.

## Regla de contenido

El contenido académico e institucional específico del portal procede exclusivamente de los materiales proporcionados para este proyecto. La página web institucional actual se utiliza únicamente como referencia visual cuando corresponde; no se incorpora su contenido académico o informativo al portal.

## Publicación

El proyecto es estático y puede publicarse en GitHub Pages. No requiere servidor propio ni Google Apps Script para que funcionen los accesos a los formularios.

## Abrir localmente

Abrir `index.html` en un navegador moderno.
